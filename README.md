## 🌟 为什么选择 Lozify？

- ⚡ **秒开速记**：纯原生 Compose 构建，轻触即记，告别漫长启动页与弹窗广告；
- 🕸️ **力导向图谱**：内置物理仿真知识图谱，让碎片闪念如神经元般自然聚合；
- 🔗 **双向链接穿梭**：`@` 快速呼出引用，底栏关联抽屉清晰洞察反向链接（Backlinks）；
- 🎨 **艺术拟物画报**：牛皮纸、收据小票、撕历日历、极客终端等 10+ 款高保真卡片长图导出；
- 🎙️ **动态声波语音**：边录边画高保真波形，支持手势精准拖拽试听与触感反馈；
- ☁️ **WebDAV 纯私密同步**：数据 100% 归你所有，零云端监控，支持坚果云、Nextcloud 等私有存储；
- 🎲 **灵感漫步 & 时光机**：随机偶遇旧想法、重温昔日同天的思绪记录；
- 📱 **桌面速记挂件**：无需打开 App，桌面一触即写。

## ⚙️ 坚果云 WebDAV 同步快速上手

1. 登录 [坚果云官网](https://www.jianguoyun.com) -> 点击右上角账户名 -> **账户信息**；
2. 选择 **安全选项** -> 找到 **第三方应用管理** -> 点击 **添加应用授权**，生成专属应用密码；
3. 打开 **Lozify -> 偏好设置 -> WebDAV 云同步**；
4. 填入服务器地址（如 `https://dav.jianguoyun.com/dav/`）、账号与刚才生成的应用密码，点击连接测试即可开启静默同步！
