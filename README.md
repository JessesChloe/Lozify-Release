## 🌟 核心特性亮点

- ⚡ **秒开速记**：极简界面，启动即记，告别臃肿加载；
- 🔗 **双向链接**：自动关联相关便签，构建专属思维网络；
- 🎙️ **语音速记**：支持录音波形条可视化播放与精准拖拽；
- ☁️ **WebDAV 纯私密同步**：数据归你所有，支持坚果云、Nextcloud 等私有云存储；
- 🌙 **全功能黑夜模式**：深度护眼暗色设计，日夜自动切换；
- 🎨 **精美分享卡片**：一键生成多种排版分享长图。
